# Preserved B1 prototype

`legacy-prototype.txt` preserves the earlier tracked `team` file byte-for-byte (including its
original concatenated prototype sections). The `team` file was contributed by Ghassen Benkaji.
It was relocated because B2 introduces `team/` as a directory. It is historical material, not an
executable module or an application replacement. Use the production assistant under
`claimguard/ai` and the current benchmark under `claimguard/benchmark` for integration work.
